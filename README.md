# Linux C&C Generals and Zero Hour Remake

Please find original EA readme in [EA_README](EA_README.md)

Currently this project is not in a functional state.



## Dependencies

* OpenGl v3.<TBD>
* Glad
* GLFW - git submodule
* Dear IMGui - git submodule
* CMake
* Ninja

## Compiling

* Clone the repository with --recursive (submodules utilized)
* mkdir build
* cd build
* cmake ../MyGenerals -GNinja
* cmake --build .

## Execution

* ./Generals.exe
